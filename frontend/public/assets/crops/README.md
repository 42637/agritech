# Crop thumbnails

These 13 crop specific vector illustrations are original local SVG assets, created for crisp, legible thumbnails at small card sizes. Each depicts a distinctive crop feature: rice panicles, a maize ear, chilli pods, peanut pods, turmeric rhizomes, cotton bolls, mung pods, sesame capsules, segmented cane stalk, tomatoes, onion bulb, pigeon pea pods, and dark urad pods. They do not depend on remote image hosts.
